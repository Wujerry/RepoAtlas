# Concentrate motion in functional signature moments

RepoAtlas uses motion to explain focus, hierarchy, progress, and state rather than animating every surface. Its more expressive visual treatment is concentrated in project discovery, the command palette, and the Project Dashboard header; dense lists, settings, diffs, and logs remain calm, while reduced-motion support and compositor-friendly animation preserve the product's performance-first identity.


Footprints is an additional functional signature surface: its date cursor and selected event link the calendar, timeline and inspector. Static local amber lighting is permitted there. Entry is bounded to 280ms total; date/category/detail transitions never delay input or data requests. Virtualized rows do not animate on scroll or pagination, and reduced-motion and hidden-window behavior disable unnecessary motion.
